# Единый выбор языка Homo Provincialis

Общий механизм: `homoprovincialis-site/js/language.js`.
Единственный ключ, который он записывает: `hp-language`, значение `en` или `ru`.

## Поведение

- При отсутствии действительного сохранённого выбора используется английский.
  Язык браузера не меняет это правило.
- Начальная загрузка не записывает английский как якобы сделанный пользователем
  выбор. Запись происходит при нажатии существующей языковой кнопки.
- На следующих страницах и после перезагрузки используется тот же язык.
- Изменение общего ключа в другой вкладке обновляет интерфейс открытой страницы.
- При отказе чтения/записи localStorage переключатель продолжает работать в памяти
  текущей страницы. Сохранение между загрузками в таких условиях гарантировать
  невозможно; бизнес-данные не используются как запасное хранилище языка.
- Поддерживаются только точные значения `en` и `ru`; некорректные значения не
  исполняются и не применяются.

Для совместимости проверяются следующие ключи, в порядке приоритета:

1. `hp-language` — основной ключ.
2. `homoprovincialis-language` — прежний выбор философского раздела и теста.
3. `hp_translation_ui_lang_v1` — прежний выбор переводческой среды.
4. `language`, затем `lang`, затем `siteLanguage` — прежний философский язык.

Берётся первое корректное значение. Старые ключи не переписываются и не удаляются.
Если они противоречат друг другу, основной ключ имеет приоритет: по старым записям
без времени изменения нельзя достоверно установить последний выбор. Следующее
нажатие языковой кнопки сохраняет однозначный общий выбор.

## Подключение приложений

`HPLanguage.get()` возвращает текущий язык, `HPLanguage.set(language)` применяет и
сохраняет явный выбор. `HPLanguage.register(renderer)` подключает существующую
функцию отображения приложения. Вызов выполняется после готовности DOM, а для
асинхронно загружаемой демократии — сразу после регистрации готового приложения.

Глобальная функция `setLanguage` оставлена для прежних кнопок. Имена
`setLibraryLanguage` и `ddLanguage` также сохранены как совместимые входы в общий
механизм. Структура ссылок и обработка навигации не менялись; параметры языка в
адреса страниц не добавлялись.

Из общего контроллера не создаются универсальные атрибуты `data-lang` на корне
всех документов: тест морали уже использует это имя для своих кнопок. Атрибут
философского языка остаётся локальной частью его собственного отображения.

## Сохранность содержания и данных

Философские тексты, переводы, словари интерфейсов, вопросы и баллы теста, данные
равноденствий, CSS, HTML-разметка интерфейсов и адреса ссылок не изменяются.
Существующие переводчики интерфейсов выполняют ту же работу, что и раньше.

Общий выбор не записывает книги, черновики, каталог переводов, ответы теста,
участников, голосования, решения или настройки сообщества. На языковой кнопке
теста удалён лишний вызов сохранения ответов: ввод пояснений, выбор ответов и
обычные кнопки теста сохраняют данные прежним способом.

Автоматические проверки сравнивают все бизнес-ключи localStorage до и после
переключения, включая прежние языковые ключи, и контролируют сами вызовы записи.
Обычное автосохранение перевода при вводе и уходе со страницы остаётся прежним.

## Локальная разработка и ограничения

В Google Chrome проверяются переходы как по настоящему localhost, так и через
`file://`. Для других браузеров/профилей правила хранения локальных файлов могут
отличаться. Выбор и бизнес-данные не переносятся автоматически между `file://`,
разными доменами, портами и профилями браузера.

Для стабильного локального адреса из корня репозитория можно запустить:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory homoprovincialis-site
```

В Windows вместо `python3` можно использовать `py`.
Адрес: `http://127.0.0.1:8000/index.html`. Настройки безопасности Chrome менять
не нужно. Правила защиты хранилища демократии и требования Web Locks сохранены.

## Тестирование

```sh
node --test tests/unified-language.test.cjs
node --test tests/open-online-library-import.test.cjs tests/world-direct-democracy-data-safety.test.cjs
```

Нужны Node.js, Playwright и установленный Chromium/Google Chrome. По умолчанию
используется `/usr/bin/chromium`; путь переопределяется переменной
`CHROMIUM_EXECUTABLE_PATH`. Для сравнения с исходной main нужна история Git с
базовым коммитом `11ec133`; для прежних проверок демократии — также `1ee2d76`.

В тестах используются только изолированные браузерные профили и синтетические
данные. Работающие пользовательские профили, реальные книги и голосования не
затрагиваются. Обвязка существующего теста библиотеки теперь отдаёт общий JS как
JavaScript; прежняя проверка неизменности HTML демократии учитывает его подключение.
