Catalogue administration (GitHub authorization)Управление каталогом (авторизация GitHub)

Only the repository owner can publish changes. Use a fine-grained GitHub token limited to the Homo-Provincialis repository, with Contents: Read and write. Do not enter your GitHub account password. Your token is kept only in this open page and is forgotten when you close or reload it.

Только владелец репозитория может публиковать изменения. Создай токен GitHub с ограниченными правами: только репозиторий Homo-Provincialis, разрешение Contents: Read and write. Не вводи пароль от аккаунта GitHub. Токен хранится только в открытой странице и забывается после её закрытия или обновления.

After authorization, Add, Edit, Move and Delete update the published JSON on GitHub for everyone. Import JSON affects this browser only; it never publishes automatically.

После авторизации добавление, изменение, перенос и удаление книг обновляют общий JSON на GitHub для всех. Импорт JSON меняет только этот браузер и не публикуется автоматически.
